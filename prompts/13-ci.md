Add CI with GitHub Actions.

1. `.github/workflows/tests.yml` running on push, pull request, and manual dispatch.
2. Cache npm and the Playwright browsers.
3. Run lint and typecheck first, then the api project, then the web project. Fail fast on
   lint.
4. Upload the HTML report, traces, and videos as artifacts with a sensible retention.
5. Publish a summary to the GitHub step summary so a reviewer sees pass/fail without
   downloading anything.
6. Add a scheduled nightly run — the targets are third-party services and a nightly run
   catches drift in them.
7. Add a status badge to the README.

Push, wait for the run, and show me the actual result. If it fails in CI but passes
locally, fix the cause rather than the symptom, and log the difference in the AI
evaluation doc — CI/local divergence is exactly the kind of thing worth writing about.
